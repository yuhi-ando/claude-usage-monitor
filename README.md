# トークンモニター（Claude Code / Codex）

Claude Code と Codex のトークン消費を、Windows のタスクマネージャー（パフォーマンス）のように
リアルタイムのグラフで見るためのローカルツールです。
<img width="1555" height="1011" alt="ChatGPT 画像 2026年11月11日 15_39_18" src="https://github.com/user-attachments/assets/a7c84b3d-4adc-4f55-979a-1415b8e2fa42" />

- 1秒ごとに更新され、グラフが右から左へ流れます
- 上のボタンで **両方 / Claude / Codex** を切り替え
- 左の一覧から「合計 / 出力 / 入力 / キャッシュ作成 / キャッシュ読込」を切り替え
- 表示期間は 60秒・10分・1時間・6時間・24時間・7日
- Claude の 5時間ブロックの消費量と残り時間、Codex の利用上限（使用率とリセットまでの時間）
- 今日の合計、モデル別・プロジェクト別の内訳（直近24時間）

## 必要なもの

- macOS（Linux / Windows でも Python 3.8 以上があれば動くはずですが、動作確認は macOS のみです）
- Python 3（macOS では `xcode-select --install` で入ります）
- Claude Code か Codex を使っていること（会話ログを読み取って集計します）

外部ライブラリは不要です。インターネット接続も要りません。

## 使い方

```bash
git clone https://github.com/yuhi-ando/claude-usage-monitor.git
cd claude-usage-monitor
sh start.sh
```

ブラウザが開き、`http://localhost:18931` にグラフが表示されます。終了は `Ctrl+C` です。

ポートを変える場合:

```bash
PORT=19000 sh start.sh
```

## 仕組みとプライバシー

読み取るのは次の場所のログだけです。

| ツール | 場所 | 環境変数で変更 |
|---|---|---|
| Claude Code | `~/.claude/projects/**/*.jsonl` | `CLAUDE_CONFIG_DIR` |
| Codex | `~/.codex/sessions/**/*.jsonl` | `CODEX_HOME` |

- トークン数とモデル名、作業フォルダ名だけを集計します。会話の本文は集計に使わず、画面にも出しません。
- 画面には作業フォルダ名がプロジェクト名として表示されます。画面共有やスクリーンショットでは注意してください。
- 既定では `127.0.0.1` だけで待ち受けるため、同じネットワークの他の人からは見えません。
  `--host` で別のアドレスを指定すると、認証なしでそのネットワークに公開されるので、信頼できる環境でだけ使ってください。
  不審な `Host` ヘッダのリクエストは拒否します（別のホスト名で開く場合は環境変数 `ALLOWED_HOSTS` にカンマ区切りで追加）。
- 集計結果を外部に送信することはありません。

## 数え方

- 「合計」は **入力 + 出力** で、入力には Claude のキャッシュ作成を含めます。キャッシュ読込は量が桁違いに多いため、合計には含めず別項目にしています。
  「両方」を選んだ合計グラフは、Claude 出力 / Claude 入力 / Codex 出力 / Codex 入力の4色で積み上げます。
- Codex のログは入力トークンにキャッシュ分を含むため、`入力 − キャッシュ読込` を「入力」としています。
  出力は推論トークンを含む値です。
  応答ごとの `token_usage_record` を優先し、同時に記録される `token_count` との二重計上を防ぎます。
  旧形式の `token_count` のみのログも、再開・圧縮による累計値のリセットに対応します。
- 速度は **tokens/分** で、直近数秒〜数時間の移動平均です（表示期間によって窓が変わります）。
- Claude の 5時間ブロックは、最初のメッセージの時刻を正時に切り捨てた時点から 5 時間を 1 ブロックとして数えます。
  利用上限の締め切りと完全に一致するとは限りません。目安として使ってください。
- Codex の利用上限は、ログに最後に記録された値を表示します。Codex を使っていない間は古い値のままです。
- 集計の対象は、直近8日分のログです。

## 制限

- 見えるのは **その Mac で動かした Claude Code / Codex の分だけ** です。別のマシンの利用量は含まれません。
- ログの形式は各ツールの内部仕様なので、将来のバージョンで変わると集計できなくなる可能性があります。
- 金額の換算はしていません（トークン数のみ）。

## SSH 先の Mac で動かしている場合

SSH 先で `python3 server.py` を起動し、手元の PC からポートフォワードして開けます。

```bash
ssh -L 18931:127.0.0.1:18931 <接続先>
# 手元のブラウザで http://localhost:18931
```
